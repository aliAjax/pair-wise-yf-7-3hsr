# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。

## 拆版归库台

作品排完后可以生成拆版单，把版面上的字模逐格归还入库：

- **建单**：作品名非空且字模不超用时才能建单；建单后版面冻结，每个落字格变为待归还。
- **逐格登记**：点击版面格子或单据字块，登记为完好、磨损或遗失；遗失必须填写责任人与说明。重复登记或超量归还会被整单拒绝。
- **库存**：部分归还只释放对应字模的占用（可用库存随之增加）；遗失的核减在完单时统一结算。
- **完单**：全部格子登记完成后拆单结束，版面自动解冻。
- **冻结期间**：字模不得减少或移除，不能清空版面、更换纸张；载入草稿与拆版冲突时保留当前版面并提示。
- 拆版单与历史记录保存在 localStorage，刷新页面后继续。

## 文件结构

- `dismantle.js` — 拆版规则：建单校验、登记校验、完单判定（纯逻辑，不碰 DOM 与库存）
- `inventory.js` — 库存状态：用量统计、归还入账、遗失核销、冻结守卫
- `app.js` — 页面交互：渲染、事件与本地持久化
