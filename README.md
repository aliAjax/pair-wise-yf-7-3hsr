# 活字排版工坊

一个纯前端本地应用，用来维护字模库、在网格版面中落字、检查字模数量是否超用、保存草稿并导出PNG预览图；
另设「拆版归库台」，把印完的版面逐格拆版归库。

直接打开 `index.html` 即可使用，也可以在本目录启动静态服务访问。数据保存在浏览器 localStorage，刷新后保留。

## 业务文件

- `js/inventory.js` —— 库存状态：字模库 / 落字 / 草稿的状态维护、超量计算、库存增减与本地持久化。
- `js/dismantle.js` —— 拆版规则：建单校验、版面冻结、逐格登记（完好 / 磨损 / 遗失）、整单拒绝、归库与解冻。
- `js/ui.js` —— 页面交互：全部渲染、事件绑定、冻结态守卫与冲突提示（toast）。

## 拆版归库规则

1. 作品名非空、版面有落字且字模未超用（已用 ≤ 库存）才能建立拆版单。
2. 建单后立即冻结版面，每个落字格成为「待归还」格子。
3. 逐格登记为完好、磨损或遗失；遗失必须填写责任人与说明，遗失字模不入库。
4. 重复登记同一格，或同一字模归还数量超过拆版落字数，整单拒绝、数据不变。
5. 部分归还只增加对应字模库存（完好 / 磨损均入库），其余格子继续待归还。
6. 全部格子登记完成后整单自动结束、版面清空并解冻；结束的拆版单保留在历史中可查遗失记录。
7. 拆版单未结束时：字模不得删除或移除，版面不能落字、清空或改纸张，草稿不能载入。
8. 草稿载入若与进行中的拆版单冲突，或草稿引用的字模已缺失，保留当前版面并弹出提示。
